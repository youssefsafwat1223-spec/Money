## Task B — SHA-256 dedup infrastructure

The current `findDuplicate` in the repository requires a known merchant and only covers
the 2-minute window. It silently skips dedup for no-merchant transactions (transfers,
ATM withdrawals). The new hash-based dedup plugs this gap.

### B1. Pure hash utility

Create new file `lib/engine/dedup/transaction_dedup.dart`:

```dart
import 'dart:convert';
import 'package:cryptography/cryptography.dart';

/// Computes a dedup hash for a parsed transaction.
/// Dedup window = 5-minute bucket. Two SMS for the same amount + currency + card
/// within the same 5-min bucket produce the same hash → duplicate.
class TransactionDedup {
  TransactionDedup._();

  static final _sha = Sha256();

  static Future<String> computeHash({
    required double amount,
    required String currency,
    String? cardLast4,
    required DateTime occurredAt,
  }) async {
    final bucket = _floorTo5Min(occurredAt.toUtc());
    final key =
        '$amount|${currency.toUpperCase()}|${cardLast4 ?? ''}|${bucket.toIso8601String()}';
    final bytes = utf8.encode(key);
    final digest = await _sha.hash(bytes);
    return digest.bytes
        .map((b) => b.toRadixString(16).padLeft(2, '0'))
        .join();
  }

  static DateTime _floorTo5Min(DateTime d) =>
      DateTime.utc(d.year, d.month, d.day, d.hour, (d.minute ~/ 5) * 5);
}
```

`cryptography` (^2.7.0) is already in `pubspec.yaml`. No new dependency needed.

### B2. DedupStore abstract interface

Create new file `lib/domain/repositories/dedup_store.dart`:

```dart
abstract class DedupStore {
  /// Returns true if this hash was already seen (duplicate).
  Future<bool> has(String hash);

  /// Records a hash → transaction_id mapping after a successful save.
  Future<void> mark(String hash, {required String transactionId});

  /// Returns the transaction ID that produced this hash, or null.
  Future<String?> transactionIdFor(String hash);
}
```

### B3. Drift implementation

Create new file `lib/data/repositories/drift_dedup_store.dart`:

```dart
import 'package:drift/drift.dart';

import '../db/app_database.dart';
import '../../domain/repositories/dedup_store.dart';

class DriftDedupStore implements DedupStore {
  const DriftDedupStore(this._db);

  final AppDatabase _db;

  @override
  Future<bool> has(String hash) async {
    final rows = await _db.customSelect(
      'SELECT 1 FROM dedup_hashes WHERE hash = ? LIMIT 1;',
      variables: [Variable.withString(hash)],
    ).get();
    return rows.isNotEmpty;
  }

  @override
  Future<void> mark(String hash, {required String transactionId}) async {
    await _db.customInsert(
      '''
        INSERT OR IGNORE INTO dedup_hashes(hash, transaction_id, saved_at)
        VALUES (?, ?, ?);
      ''',
      variables: [
        Variable.withString(hash),
        Variable.withString(transactionId),
        Variable.withString(DateTime.now().toUtc().toIso8601String()),
      ],
    );
  }

  @override
  Future<String?> transactionIdFor(String hash) async {
    final row = await _db.customSelect(
      'SELECT transaction_id FROM dedup_hashes WHERE hash = ? LIMIT 1;',
      variables: [Variable.withString(hash)],
    ).getSingleOrNull();
    return row?.read<String>('transaction_id');
  }
}
```

  final hash = await TransactionDedup.computeHash(
    amount: parsed.amount,
    currency: parsed.currency,
    cardLast4: parsed.cardLast4,
    occurredAt: occurredAt,
