## Previous host — rollback, still live

```
https://qirsh-legal.albaraai-dev.workers.dev
```

**Do not delete or disable it.** It stays live because:

- it is the rollback target if `qirsh.site` has a problem;
- builds already in users' hands have that URL compiled in and will keep
  requesting it;
- a store listing may still reference it during review.

It was never a placeholder — it was an approved temporary production host, and
it did its job. Retire it only when no shipped build still points at it, and
prefer redirecting it to `qirsh.site` over removing the name.

## Configuration — migrated 2026-08-30

| Where | Value |
|---|---|
| Built-in default, `app/lib/core/config/legal_urls.dart` | `https://qirsh.site` |
| Pinned expectations, `app/test/core/legal_urls_test.dart` | `https://qirsh.site` |
| Codemagic `LEGAL_BASE_URL`, `supabase` variable group | **`https://qirsh.site`** — see below |

The built-in default protects **users** if the variable is absent; the Codemagic
variable declares **release intent**. Both are required — see
[`legal_release_checklist.md`](legal_release_checklist.md).

⚠️ The Codemagic variable still holds the **old Workers URL** until someone
updates it. That does not break anything — the built-in default already points
at `qirsh.site`, so links work either way — but a production build would declare
a host that is no longer canonical. Treat it as a release-configuration defect
and fix it before signing.
