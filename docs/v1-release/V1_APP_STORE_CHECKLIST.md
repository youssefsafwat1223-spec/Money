## 3. Languages — the line that changes the listing

The app declares no `CFBundleLocalizations`. Measured UI coverage is **11%**:
338 ARB keys per language against 1,745 hardcoded Arabic strings across 74
widget files.

**Declare Arabic only.** Claiming English would put a mostly-Arabic UI in front
of a reviewer who switches language — a rejection risk, and untrue. Help, the
coach marks and all 26 category names are genuinely bilingual; the rest is not.
See V1_LOCALIZATION_MATRIX.md.

* Gitignored (`app/ios/.gitignore:21`); **no commit contains it** — local only.

Verified absent from tracked source and from every commit in this effort.
