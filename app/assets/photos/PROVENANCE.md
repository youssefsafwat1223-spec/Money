# Qirsh approved photographic assets

These 14 WebP files are byte-for-byte copies of the original images in
`design-preview/qirsh-redesign/assets/photos/`. The original generation prompts,
logo-compositing notes, focal points and review notes remain in that directory
(`manifest.json`, `CREDITS.md`, `REPORT.md`).

The prototype described these as demo assets. The owner subsequently approved
using the original HTML imagery in the production Flutter visual implementation.
No images were regenerated or redrawn during this migration.

Brand scenes use the owner's original Qirsh logo/coin composites. Goal scenes
retain their natural photographic colors. No external image service is used.
